{% comment %} Shared shell for the transactional messages. Included, not extended: templated_mail reads `subject` / `text_body` / `html_body` off the *top-level* nodelist of the template it renders, and with `{% extends %}` that nodelist is a single ExtendsNode — every block would come back empty and the mail would go out blank. An include renders inside the block instead, which works. Callers set `title`, `intro`, `cta_label`, `action_url` and `fallback` before including this. Table layout and inline styles, both deliberate: mail clients have no flexbox and most of them strip
